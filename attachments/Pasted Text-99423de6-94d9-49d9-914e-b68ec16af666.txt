You are an expert product designer + clinical psychologist + mobile engineer. Design a complete, production-ready mobile app called “Reset Path” (or similar name) that helps adults break compulsive pornography use and masturbation habits using evidence-based methods.

CORE PRINCIPLES (non-negotiable):
- Grounded in CBT + Acceptance and Commitment Therapy (ACT) + mindfulness-based relapse prevention. Do NOT use heavy shame, moralizing, or “you’re disgusting” tactics.
- Compassionate, private, science-informed. Relapse is treated as data, not identity failure.
- Focus on values, psychological flexibility, environmental design, and building a life worth living — not just “don’t fap.”
- Privacy first: local-first or end-to-end encrypted data, no selling user data, optional anonymous community only.
- Works offline for core tools (urge surfing, breathing, journal).
- Inclusive: works for any gender/orientation; avoid assuming everyone has a partner or religious motivation.

PRIMARY USER JOURNEY:
1. Onboarding (5–8 screens):
   - Short, validated-style assessment (adapt PPCS-6 or similar + questions on frequency, distress, PIED if relevant, main triggers, current “why”).
   - Values clarification exercise (what kind of person/partner/friend do they want to be?).
   - Choose goal: full abstinence reboot, harm reduction, or “no porn but masturbation allowed” (user decides).
   - Set up friction: guide them to enable content blockers, Screen Time / Digital Wellbeing restrictions, night lock hours, phone-out-of-bedroom rule.
   - Write 3-sentence “Why” that is saved and shown during urges.

2. Home / Today screen:
   - Current streak + TOTAL clean days (both matter).
   - Daily check-in: mood (1–5), energy, sleep, urge intensity if any, one sentence journal.
   - Today’s micro-commitment from the program.
   - Quick SOS / Panic button (always visible).

3. SOS / Urge Protocol (the most important feature):
   - One-tap Panic button.
   - Guided 8–12 minute Urge Surfing session: name the urge, locate it in the body, breathe, observe the wave, rate intensity 0–10 every 60–90 seconds, then transition to a pre-chosen replacement action.
   - Alternative tracks: 4-7-8 breathing, 5-4-3-2-1 grounding, 2-minute cold-exposure reminder, “leave the room + 20 push-ups,” call/text accountability contact.
   - After session: log outcome (surfed / delayed / slipped) + what triggered it. Auto-suggest pattern insight later.

4. Structured 90-Day Program + Beyond:
   - Week-by-week modules (short videos or audio + text + exercise):
     Week 1–2: Education (how the reward system works, supernormal stimulus, why willpower fails), trigger mapping, environment design.
     Week 3–4: ACT skills — defusion, acceptance, self-as-context.
     Week 5–8: Values + committed action, building competing rewards (exercise, social, creative).
     Week 9–12: Relapse prevention, identity shift (“I am someone who…), long-term maintenance.
   - Daily 5–12 minute lesson or practice.
   - Optional “reboot calendar” with expected phases (days 3–7 wall, possible flatline, clarity returning) so users aren’t shocked.

5. Insights & Pattern Engine:
   - After 14 days of logging, show heatmaps: time of day, day of week, emotion, location, preceding activity.
   - “Your top 3 triggers” + suggested environmental or behavioral changes.
   - Relapse analysis: “Last 3 slips had X in common.”

6. Tools library:
   - Journal with prompts (values, what I’m avoiding, what I actually need).
   - Cognitive restructuring worksheets (catch the rationalization).
   - Replacement activity library (user can add their own).
   - Breathing / body scan / short meditations.
   - Optional content-blocker status check and “how to lock it down harder” guides for iOS/Android.
   - Night-mode lock reminder.

7. Progress & Motivation (anti-shame design):
   - Visualizations that celebrate total days and skills practiced, not only unbroken streaks.
   - “Identity statements” the user writes and reviews.
   - Gentle notifications at historically high-risk times (user-configurable).
   - If they slip: compassionate reset flow + “what can we change in the system?” not “you failed.”

8. Optional layers (user can disable):
   - Private accountability partner (share streak + weekly summary only).
   - Moderated, anonymous community feed with strict no-trigger rules.
   - AI coach: conversational, trained only on CBT/ACT/mindfulness scripts. Never gives sexual advice, never shames. Can run a 3-minute values reminder or defusion exercise on demand.

TECH & UX REQUIREMENTS:
- Native iOS + Android (or high-quality Flutter/React Native).
- Dark mode, calm color palette (deep blues/greens, no neon gamification that feels like a casino).
- Fast, simple, thumb-friendly. Panic button reachable in <2 taps from lock screen if possible (widget).
- Local notifications, background-safe.
- Export data / delete account easily.
- Accessibility: large text, VoiceOver, low-stimulation mode.
- Monetization suggestion: free core tools (SOS, tracker, basic education) + affordable subscription for full program, AI coach, and insights. No dark patterns.

CONTENT TONE:
- Direct, adult, non-judgmental, slightly warm. Speak like a competent coach who has seen this hundreds of times.
- Use “urge,” “habit loop,” “values,” “psychological flexibility.” Avoid “sin,” “purity,” or excessive “warrior” language unless the user chooses that tone.
- Include short science explainers with citations to key papers (Kühn & Gallinat, Voon, ACT RCTs, CBT meta-analyses) in an “Learn” section.

1. Full information architecture + user flow diagrams (text).

3. Data model (what we store and why).
