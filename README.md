# Dayring

Timed daily routines with a growing streak plant, Explore templates, reminders, and stats.

## Run

```bash
npm install
npm run dev
```

App listens on port 8080 by default in this scaffold.

## Improvisation (v2)

Sharper Dayring while keeping the plant/streak DNA, sun yellow accent, and bottom tabs.

- **First-run onboarding** — Name your plant, pick 1–2 starter templates; skipped once done (legacy installs auto-skip).
- **Run juice** — Clearer step transitions, progress dots, plant-tied completion celebration (CSS confetti + pulse).
- **Smarter Today** — Time-of-day routine priority, highlighted “Next up” card, inviting empty state → Explore.
- **Richer plant stages** — Nine earned stages (Seed → Grove) with bloom accents; plant name in Today / Stats / You.
- **Polish** — Micro-interactions, sun CTA contrast, dark mode preserved.
- **Post-run mood check** — 😊😐😔 saved on completion; tiny mood trend on Stats.
